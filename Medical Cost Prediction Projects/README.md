# **Experiment Overview**

This project is designed as a structured experimental study on the **Medical Cost Prediction** problem, with a focus on understanding how different regression models behave under the same data conditions.

Rather than focusing solely on model performance, the goal is to systematically analyze the relationship between data preprocessing, feature representation, and model behavior across multiple algorithms.

The following models were implemented:

1. Multiple Linear Regression
2. Polynomial Regression
3. Support Vector Regression (SVR)
4. Decision Tree Regression
5. Random Forest Regression

Each model was applied to the same dataset using a consistent experimental framework to ensure fair and meaningful comparison.

This work emphasizes a core principle in machine learning:

- performance is driven not only by the choice of model, but by how well the data is understood and prepared.

All detailed experimentation steps including preprocessing strategies, transformations, and evaluation procedures are fully documented within the notebooks.
